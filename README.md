# SakaMind

A WoW Forever add-on, in the works, that shares defensive cooldowns within a
core party.

Status, 2026-11-10: research done ([docs/RESEARCH.md](docs/RESEARCH.md)). A
test add-on, SakaMind Probe, settles the open points in one dungeon run
([docs/TEST-RUN.md](docs/TEST-RUN.md)).

## Installing the test add-on

Install "SakaMind" with the CurseForge app, on your WoW Forever
installation. Or download the zip from this repository's releases and
extract it into `World of Warcraft\_forever_\Interface\AddOns\`. Restart the
game and type `/smp` for its commands.

The probe tests only between players who run it: it says hello on the group
channel, and its automatic test messages go only to other probe users.
